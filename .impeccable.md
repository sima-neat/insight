## Design Context

### Users

Insight is used by developers and application engineers building and validating vision ML applications with the Neat SDK and SiMa DevKits. They use it to inspect workspaces, prepare test streams, monitor multi-channel video and inference metadata, and diagnose whether failures originate in the application, stream path, SDK environment, or target device.

### Brand Personality

Developer-focused, precise, and calm. The interface should build confidence during technical workflows by making system state, limits, and recovery actions explicit without becoming visually noisy or alarmist.

### Aesthetic Direction

Maintain the existing light SiMa visual language: blue and teal accents, restrained tinted surfaces, clear Sora/Inter typography, compact operational controls, and accessible technical detail. New UI should integrate with existing panels and control patterns rather than introduce a separate visual theme. Target WCAG AA accessibility, including keyboard focus, semantic controls, sufficient contrast, and reduced-motion-safe behavior.

### Design Principles

1. Make runtime state and environmental constraints visible at the point of use.
2. Pair every limitation or error with a concrete recovery action.
3. Keep frequent workflows visually quiet; reveal technical detail progressively.
4. Preserve information density without sacrificing scanability or accessibility.
5. Match established Insight components, typography, color tokens, and interaction behavior.
