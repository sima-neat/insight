Building the sima-mipi-util Debian package
------------------------------------------

Preferred: use the build script (what CI runs). It builds from a clean tree,
stamps the version, and prints the resulting .deb path.

  ./build-deb.sh dist                 # -> dist/sima-mipi-util_<version>_arm64.deb
  VERSION=1.2.3 ./build-deb.sh dist   # override the version (CI passes a
                                      # branch/tag-derived value)

Validate the result:

  dpkg-deb --info    dist/sima-mipi-util_*_arm64.deb
  dpkg-deb --contents dist/sima-mipi-util_*_arm64.deb

Distribution
------------
This package is built, validated, and published as its own Vulcan package
(gh:sima-neat/insight/mipi-util) by .github/workflows/mipi-util-vulcan-ci.yml
on pushes that touch mipi-util/. End users install it with:

  sima-cli neat install insight/mipi-util@<branch-or-tag>

The Vulcan package bundles the .deb plus install_sima_mipi_util.py
(from scripts/install-vulcan-sima-mipi-util.py), which installs it via apt so
the runtime dependencies in DEBIAN/control are pulled in.

Manual builds
-------------
There is no maintained step-by-step recipe: postinst verifies the bundled
wheel set (usr/share/sima-mipi-util/wheels/ with SHA256SUMS and PYTHON_TAG,
plus requirements-runtime.txt) at install time, so a hand-rolled layout
that skips them fails to configure. ./build-deb.sh stages everything —
read it for the exact steps if you need them.
