# Insight

Insight — це консоль для перевірки та тестування, яка працює в браузері та призначена для розробки візуальних застосунків Neat. Вона об’єднує різні компоненти циклу візуального середовища виконання в одному місці: робочий простір проєкту, тестові медіафайли, налаштування джерела потокового відео, пряме WebRTC відео, метадані та заплановане місце для зберігання системної/оперативної статистики.

Використовуйте Insight, коли вам потрібно швидко отримати відповіді на практичні питання, що виникають під час розробки.

- Які файли, моделі, пакети та артефакти профілювання містяться в моєму робочому просторі?
- Які тестові медіафайли доступні, і які потокові джерела відтворюються?
- Чи відтворює моя програма відео на потрібному каналі?
- Чи надходить метаінформація синхронно з відеокадром?
- Чи проблема пов’язана з програмою, шляхом потоку даних, чи з середовищем виконання пристрою?

Insight постачається разом із середовищем розробки Neat і також доступний як пакет Neat, який можна встановити або оновити за допомогою `sima-cli neat install`. У SDK Insight автоматично налаштовується з відображеннями портів хоста, щоб браузер, DevKit або інший пристрій у мережі могли підключатися до його інтерфейсу користувача, потокових джерел і портів для відтворення відео.

## Швидкий старт

У середовищі розробки Neat, спочатку перевірте, чи запущено Insight:

```bash
insight-admin status
```

Потім відкрийте Insight у веб-переглядачі:

```text
https://localhost:9900
```

Якщо ви переглядаєте сторінку з іншого пристрою в тій самій мережі, використовуйте IP-адресу хоста SDK:

```text
https://<host-ip>:9900
```

Якщо під час створення SDK стандартні порти були недоступні, порти, які використовуються для взаємодії з браузером, можуть відрізнятися. Щоб переглянути поточну карту портів, виконайте цю команду всередині SDK:

```bash
neat --json
```

Перегляньте `insight.webUiUrl`, щоб отримати доступ до основного інтерфейсу користувача, і `exposedPorts` для протоколів RTSP, відео UDP, метаданих UDP і WebRTC, а також для інтерфейсу перегляду відео.

Основний цикл розробки такий:

1. Відкрийте Insight.
2. Завантажте або виберіть медіафайли в розділі «Джерела медіа».
3. Запустіть один або кілька потокових джерел.
4. Запустіть свою програму Neat.
5. Переглядайте виведені дані та метадані, що відображаються у вікні перегляду відео.
6. Під час налаштування програм, які працюють на DevKit або на іншому зовнішньому пристрої, використовуйте карту портів SDK.
7. Використовуйте робочий простір для перегляду артефактів, а також використовуйте заповнювач «Статистика», щоб зрозуміти, де саме в наступній версії будуть розміщені системні/діагностичні дані середовища виконання.

Якщо у вас ще немає файлів із медіавмістом, почніть зі стандартних тестових відео, перелічених у розділі [Common Workflows](workflows.md#import-standard-test-videos).
