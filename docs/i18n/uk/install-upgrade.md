# Встановити та оновити.

Insight постачається разом із середовищем розробки Neat. Його також можна встановити безпосередньо на Modalix DevKit і оновити за допомогою `sima-cli neat install`.

## У середовищі розробки Neat.

Коли контейнер SDK запускається з увімкненою функцією Insight, Insight автоматично встановлюється, налаштовується та підтримується в робочому стані. Сервер прослуховує з’єднання через HTTPS, а SDK публікує набір портів для браузера, DevKit та інших зовнішніх клієнтів.

Перевірте стан служби:

```bash
insight-admin status
```

Відкрийте Insight у веб-переглядачі:

```text
https://localhost:9900
```

Якщо ви переглядаєте вміст з іншого пристрою в тій самій мережі, використовуйте IP-адресу хоста SDK:

```text
https://<host-ip>:9900
```

Порт веб-інтерфейсу за замовчуванням — `9900`, але SDK може призначити інший порт хоста, якщо `9900` вже використовується. Команда `neat` відображає фактичну URL-адресу веб-інтерфейсу Insight і відображає відповідність між портами:

```bash
neat --json
```

Використовуйте `insight.webUiUrl` для основного інтерфейсу користувача. Використовуйте масив `exposedPorts` під час налаштування програм DevKit, клієнтів RTSP або зовнішніх джерел медіаданих.

## На DevKit.

Insight можна встановити безпосередньо на Modalix DevKit. Це зручно, коли вам потрібно, щоб консоль перевірки працювала на цільовому пристрої, або коли ви перевіряєте окрему конфігурацію DevKit.

Встановіть Insight за допомогою `sima-cli`:

```bash
sima-cli neat install insight@{release-tag}
```

Для збірок, призначених для розробки, замініть тег версії на назву гілки або тегу, який ви хочете встановити:

```bash
sima-cli neat install insight@main
```

Після встановлення активуйте створене віртуальне середовище та запустіть Insight:

```bash
source ~/.simaai/neat-insight/venv/bin/activate
neat-insight --port 9900
```

Потім відкрийте:

```text
https://<devkit-ip>:9900
```

Коли Insight запускається безпосередньо на DevKit, програми на цьому DevKit зазвичай можуть використовувати стандартні локальні порти. Коли програми, що знаходяться поза DevKit, підключаються до нього, використовуйте IP-адресу DevKit і порти, відкриті цим конкретним екземпляром Insight.

## Оновіть Insight.

Оскільки Insight поширюється як артефакт Neat, ви можете оновити його, використовуючи той самий процес `sima-cli neat install`, який використовується для встановлення.

Для випуску нової версії:

```bash
sima-cli neat install insight@{release-tag}
```

Щоб отримати останню версію зі певної гілки:

```bash
sima-cli neat install insight@main
```

У середовищі розробки Neat, Insight зазвичай запускається з `/opt/neat-insight/venv`. Щоб оновити керований екземпляр SDK, встановіть його в цьому віртуальному середовищі та перезапустіть службу:

```bash
NEAT_INSIGHT_VENV_DIR=/opt/neat-insight/venv sima-cli neat install insight@main
supervisorctl restart neat-insight
```

Якщо для вашого образу SDK потрібні підвищені права доступу для `/opt/neat-insight`, запустіть команду встановлення з відповідними правами для вашого середовища.
