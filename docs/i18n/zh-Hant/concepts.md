# 概念

Insight 會在你建置和測試應用程式時，與你的應用程式並排運作。它不會取代 Neat 函式庫或你的應用程式執行階段。相反地，它會為你提供一個瀏覽器視窗，讓你檢視通常分散在 SDK 容器、DevKit、日誌檔案、媒體檔案和串流埠中的各種元件和訊號。

在 Neat 開發環境中，Insight 也會充當測試媒體服務。它可以將上傳的媒體轉換為串流來源，並透過 WebRTC 視訊檢視器來呈現應用程式的輸出。當應用程式在 SDK 容器外部執行時（例如在 DevKit 上），請使用來自 `neat --json` 的 SDK 埠對應，以找出外部用戶端應使用的主機埠。

![ Neat Insight 開發迴圈，展示工作區檢視、串流來源設定、應用程式輸出、WebRTC 檢視和執行階段診斷功能。](images/insight-development-loop.jpg)

典型的迴圈如下：

1. 檢查工作區和應用程式的相關檔案。
2. 上傳或選擇媒體檔案以進行測試。
3. 將媒體檔案轉換為串流來源，例如 `rtsp://127.0.0.1:8554/src1` 或 HTTP MJPEG 端點，以進行 MJPEG 攝影機模擬。
4. 使用這些資源來執行您的應用程式。
5. 將申請影片和中繼資料輸出傳送到對應的 Insight 觀看頻道。
6. 在「視訊檢視器」中查看應用程式的輸出結果。
7. 使用系統資訊和日誌來診斷效能或執行階段問題。本版本中的「統計資料」檢視僅為佔位符，預計在下一個版本中完成。

## Insight 的用途是什麼？

Insight 專為視覺機器學習應用程式的開發和驗證而設計。它能幫助您在測試執行期間，確認媒體、執行階段輸出、中繼資料和系統行為是否一致。

使用 Insight 來：

- 準備可重複使用的影片素材。
- 確認應用程式的輸出是否已傳送到預期的顯示管道。
- 為常見的視覺輸出結果呈現中繼資料疊加層。
- 檢查產生的模型、套件、原始碼和分析檔案。
- 將應用程式的症狀與裝置或 SDK 的執行階段狀態進行比較。統計資料檢視是預計用於此工作流程的位置，但目前版本中它僅為一個佔位符。

## 什麼是 Insight 裡沒有的

Insight 不會取代您的 IDE。請繼續使用您平常使用的編輯器、終端機、版本控制流程和建置工具。Insight 透過提供工作區構件、測試媒體、串流路由、視訊輸出、中繼資料疊加層和執行階段診斷的瀏覽器介面，來完善您的工作流程。
