# Insight

Insight는 Neat 비전 애플리케이션 개발을 위한 브라우저 기반 검사 및 테스트 콘솔입니다. 비전 런타임 루프의 여러 요소를 한 곳에 모아 제공합니다. 여기에는 프로젝트 작업 공간, 테스트 미디어, 스트리밍 소스 설정, 실시간 WebRTC 비디오, 메타데이터 오버레이, 그리고 시스템/런타임 통계가 표시될 위치 등이 포함됩니다.

실용적인 개발 질문에 신속하게 답변하고 싶을 때 Insight를 사용하세요.

- 내 작업 공간에 어떤 파일, 모델, 패키지, 프로파일링 결과물이 있나요?
- 어떤 테스트 미디어 파일이 사용 가능한가요? 그리고 어떤 스트리밍 소스가 재생되고 있나요?
- 제 애플리케이션이 예상대로 지정된 채널에서 비디오를 출력하고 있습니까?
- 메타데이터가 비디오 프레임과 함께 동기화되어 전송되고 있습니까?
- 문제의 원인이 애플리케이션, 스트림 경로, 또는 장치의 런타임에 있습니까?

Insight는 Neat 개발 환경과 함께 제공되며, `sima-cli neat install`을 사용하여 설치하거나 업그레이드할 수 있는 Neat 아티팩트 패키지로도 제공됩니다. SDK에서 Insight는 호스트 포트 매핑을 통해 자동으로 구성되므로 브라우저, DevKit 또는 네트워크의 다른 장치가 UI, 스트리밍 소스 및 비디오 렌더링 포트에 연결할 수 있습니다.

## 빠른 시작

Neat 개발 환경에서 먼저 Insight가 실행 중인지 확인합니다.

```bash
insight-admin status
```

그런 다음 브라우저에서 Insight를 엽니다.

```text
https://localhost:9900
```

동일 네트워크의 다른 장치에서 접속하는 경우, SDK 호스트 IP 주소를 사용하십시오.

```text
https://<host-ip>:9900
```

SDK가 생성될 때 기본 포트가 사용 가능하지 않은 경우, 브라우저에 표시되는 포트가 다를 수 있습니다. 실제 포트 매핑을 확인하려면 SDK 내에서 다음 명령을 실행하세요.

```bash
neat --json
```

주요 UI는 `insight.webUiUrl`에서 확인하고, `exposedPorts`에서 RTSP, 비디오 UDP, 메타데이터 UDP, WebRTC 및 비디오 뷰어 UI 설정을 확인하세요.

기본 개발 루프는 다음과 같습니다.

1. Insight를 엽니다.
2. 미디어 소스에서 미디어를 업로드하거나 선택하세요.
3. 하나 이상의 스트리밍 소스를 시작합니다.
4. Neat 애플리케이션을 실행하세요.
5. 비디오 뷰어에서 출력 결과와 메타데이터 오버레이를 확인하세요.
6. DevKit 또는 다른 외부 장치에서 실행되는 애플리케이션을 구성할 때 SDK 포트 맵을 사용하십시오.
7. 작업 공간을 사용하여 아티팩트를 검사하고, Stats 자리 표시자를 사용하여 다음 릴리스에서 시스템/런타임 진단 정보가 어디에 표시될지 확인합니다.

미디어 파일이 아직 없는 경우, [Common Workflows](workflows.md#import-standard-test-videos)에 나열된 표준 테스트 비디오부터 시작하세요.
