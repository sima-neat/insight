# 개념

Insight 애플리케이션을 구축하고 테스트하는 동안 애플리케이션 옆에 위치합니다. 기존 애플리케이션을 대체하지 않습니다. Neat 라이브러리 또는 애플리케이션의 런타임입니다. 대신, 일반적으로 SDK 컨테이너에 분산되어 있는 아티팩트와 신호에 대한 브라우저 보기를 제공합니다. DevKit로그 파일, 미디어 파일, 스트리밍 포트 등이 있습니다.

다음은 Neat 개발 환경, Insight 또한 테스트 미디어 서비스 역할도 합니다. 업로드된 미디어를 스트리밍 소스로 변환하고 애플리케이션 출력을 통해 렌더링할 수 있습니다. WebRTC 비디오 뷰어입니다. 애플리케이션이 SDK 컨테이너 외부에서 실행될 때, 예를 들어 다음과 같은 경우에 사용됩니다. DevKit다음에서 SDK 포트 맵을 사용하세요. `neat --json` 외부 클라이언트가 사용해야 하는 호스트 포트를 찾습니다.

![Neat Insight 개발 루프는 작업 공간 검사, 스트리밍 소스 설정, 애플리케이션 출력, WebRTC 보기 및 런타임 진단을 보여줍니다.](images/insight-development-loop.jpg)

일반적인 루프는 다음과 같습니다.

1. 작업 공간과 애플리케이션 관련 파일을 검사합니다.
2. 테스트를 위해 미디어 파일을 업로드하거나 선택하세요.
3. 미디어 파일을 스트리밍 소스(예: `rtsp://127.0.0.1:8554/src1`) 또는 MJPEG 카메라 시뮬레이션을 위한 HTTP MJPEG 엔드포인트로 변환합니다.
4. 해당 소스들을 사용하여 애플리케이션을 실행해 보세요.
5. 신청 영상과 메타데이터 출력을 해당 Insight 시청 채널로 전송합니다.
6. 비디오 뷰어에서 애플리케이션의 출력 결과를 확인하세요.
7. 성능 또는 런타임 문제를 진단하기 위해 시스템 정보와 로그를 사용하십시오. 통계 보기 기능은 이번 버전에 임시로 포함되어 있으며, 다음 버전에 완성될 예정입니다.

## Insight는 무엇을 위한 것인가요?

Insight는 비전 ML 애플리케이션 개발 및 검증을 위해 설계되었습니다. 테스트 실행 중에 미디어, 런타임 출력, 메타데이터 및 시스템 동작이 예상대로 작동하는지 확인하는 데 도움이 됩니다.

다음과 같은 목적으로 Insight를 사용하세요.

- 반복적으로 사용할 수 있는 비디오 입력을 준비합니다.
- 애플리케이션의 출력 결과가 예상되는 시청 채널에 제대로 전달되는지 확인합니다.
- 일반적인 비전 처리 결과에 메타데이터 오버레이를 표시합니다.
- 생성된 모델, 패키지, 소스 코드, 프로파일링 결과물을 검사합니다.
- 애플리케이션 증상과 장치 또는 SDK 런타임 상태를 비교합니다. 통계 보기(Stats view)는 이 워크플로를 위한 계획된 위치이지만, 현재 버전에서는 임시 위치로 제공됩니다.

## Insight가 아닌 것은 무엇인가

Insight는 기존 IDE를 대체하지 않습니다. 평소에 사용하던 편집기, 터미널, 소스 관리 워크플로 및 빌드 도구를 계속 사용하십시오. Insight는 작업 공간의 아티팩트, 테스트 미디어, 스트림 라우팅, 비디오 출력, 메타데이터 오버레이 및 런타임 진단 정보를 브라우저 기반으로 제공하여 기존 워크플로를 보완합니다.
